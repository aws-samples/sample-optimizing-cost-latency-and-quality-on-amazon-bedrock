# Documentation maintenance

When the task is to edit documentation:

1. Use `get_documentation_style` to look up the current writing conventions.
2. Check that the title explains the page's purpose.
3. Use sentence case for headings and expand abbreviations on first use.
4. Keep ordered steps in the sequence the reader should perform them.
5. Check that examples use consistent names and units.

This procedure is for documentation edits. It does not determine return or
billing eligibility.
